# 欢迎使用博客模板

这是一个基于 **Material 3** 的纯静态博客模板。

## 快速开始

1. 修改 `assets/site.config.json`。
2. 将文章 Markdown 文件放入 `posts/`。
3. 在 `posts/posts.json` 中添加文章索引。
4. 将图片放入 `images/`，或者直接使用图片 URL。
5. 部署到 Cloudflare Pages、GitHub Pages 等静态托管平台。

### Markdown

支持常用 Markdown 语法，并支持到五级标题。

#### 文章主题色

文章页会根据文内头图生成主题色。

##### 五级标题

五级标题可以正常显示，但默认不进入右侧文章目录。
